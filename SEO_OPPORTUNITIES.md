## Criterio de decisión

Crear una landing únicamente cuando se cumplan todos estos puntos:

1. Hay impresiones o demanda local verificable para una intención diferenciada.
2. Nanci Nails ofrece realmente el servicio.
3. Existen precio, duración y condiciones confirmados.
4. Hay suficiente contenido y material visual propio para no producir thin
   content.
5. Se define qué página será canónica para la intención y cómo enlazará con las
   páginas existentes.
